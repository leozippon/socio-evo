The stop itself went right (the run's process, found by the anchored pattern, exited within two seconds with status interrupted), but the shell that ran the stopping script was killed in turn: the script's text, written through a heredoc in the same command that ran it, carried the pattern by which the script ended the evaluation chains, and so matched its own wrapper.
