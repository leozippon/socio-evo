# Current-job context

Work uses the current job's original observed operations across visits. Summaries remain useful outside Work and in nightly reflection. Neither default Work context nor active recall injects the current job's summaries.

When all original records fit, include them all. Under the configured input budget, retain a contiguous recent suffix and state the omitted prefix range. The most recent executed command/test feedback and later receipts are required context, including during internal choices and format retries. If that material alone exceeds capacity, report the overflow rather than silently hiding it. Source journals are never modified by packing.

Explicit work-record reads name an owned previous job outside current assignments. Reading history cannot replace current feedback. Previously read pages remain separately budgeted within the decision; repeated identical reads reuse their entry. Existing Activity-scoped skill selection continues normally.

Validation checks original early/middle/latest records across Work visits, summary exclusion through recall, skill selection and retry continuity, historical-job permissions and pagination, future-record isolation, and explicit omission under pressure. A frozen experiment request is compared with the new original-log projection while preserving its other context, with counts and hashes reported without resident private text.
